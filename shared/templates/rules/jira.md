# Jira 규칙

- 담당자·보고자는 등록하는 사람 본인이다. 앱이 [Jira에 등록]을 누를 때 자동으로 넣으니 못 한다고 말하지 않는다.
- 제목은 무엇을 하는지 한 줄로 짧게 쓴다.
- 설명은 Jira 위키 문법으로 `h3. 배경` → `h3. 할 일` → `h3. 완료 조건` 순서로 정리한다.
- 개발 일은 개발용 유형(보통 Story), 회의·문서·운영 같은 일반 업무는 Task 로 고른다.
- 기본값에서 바꾸는 건 사용자가 따로 말한(강조한) 항목뿐이다.

## 우리 팀 기본값

(아직 없음. 프로젝트 키, 이슈 유형, Original Estimate, Target start·end 규칙, worklog 를 남길 고정 이슈를 여기에 한 줄씩 적어요.
비어 있으면 김비서가 처음 Jira 를 등록할 때 물어보고, [규칙에 저장]을 누르면 이 파일에 채워져요.)
